## 重新生成 PPT

```powershell
python -m pip install python-pptx==1.0.2 pillow
python report/generate_ppt.py     # 输出 report/项目汇报.pptx
```

脚本只用 `report/screenshots/` 里的图片，不依赖临时目录；数字全部出自 `report/项目总结报告.md` 与 `data/processed/` 的实测产物，不手写编造。
