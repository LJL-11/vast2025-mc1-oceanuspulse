# MC1 数据说明

> 依据官方 `MC1-数据说明-官方.docx` + 本地全量审计（2026-11-04）整理。可复核产物为 `data/processed/quality_report.json`，运行 `python -m pipeline.run` 生成。

## 总览

| 项 | 值 |
|---|---|
| 文件 | `data/raw/MC1_graph.json`（6.5MB） |
| 结构 | 有向多重图（Directed Multigraph），networkx `node_link_data()` 格式 |
| 节点 | 17,412 个（本地实测 16 个弱连通分量；官方说明写 18） |
| 边 | 37,857 条 |
| 性质 | 官方合成数据；原始证据保留，模式与时间疑点单独标记 |

**加载方式**：

```python
from pipeline.common import load_dataset
dataset = load_dataset()  # 默认以赛题中的 2040 年为观察截点
G = dataset.graph        # nx.MultiDiGraph；不依赖 NetworkX links/edges 的默认字段变化
```

## 关键事实（实测）

- **Sailor Shift**：Person 节点 `id=17255`，相连边 60 条
- **流派 Top10**（Song 维度）：Dream Pop 590、Indie Folk 342、Synthwave 308、Doom Metal 268、Oceanus Folk 235、Alternative Rock 205、Southern Gothic Rock 185、Indie Rock 156、Americana 145、Psychedelic Rock 140
- **时间跨度**：作品 release_date 覆盖 1975–2040；2040 是故事观察时点，2026 之后的年份并非异常，不能按电脑日期删除。
- 示例节点：`{"Node Type": "Song", "name": "Breaking These Chains", "single": true, "release_date": "2017", "genre": "Oceanus Folk", "notable": true, "id": 0}`

## 数据两大来源（官方说明）

1. 众包的音乐影响力知识库：人工标注的采样/翻唱/启发关系
2. 记者 Silas 标注的人气数据：`notable` 与 `notoriety_date` 基于销量/流媒体/榜单排名

## 2026-11-04 全量审计结果

| 检查项 | 实测结果 | 处理方式 |
|---|---|---|
| 弱连通分量 | 16；最大分量 17,277 个节点，含 Sailor Shift | 保留全部分量，记录与官方 18 的差异 |
| 年份解析 | 4,611 个作品均有有效发行年；未发现创作晚于发行、登榜早于发行 | 原字符串保留为 `raw_attributes`，增加整数年份；不臆造“修复” |
| notable 作品 | 4,297；其中 3,648 没有登榜年份（84.90%） | 未知年份为 null；649 个已知年份才进入登榜事件与时差统计 |
| 自环 | 1 条：`4430:4430:0`，CoverOf | 原图保留；不计入影响传播和流派流量 |
| 重复语义关系 | 3 条 PerformerOf，多重边 key 不同 | 原图保留；作品署名以集合去重，避免重复计作品和合作 |
| 影响时间顺序疑点 | 84 条借鉴作品发行早于被引用作品 | 标记 `influence_chronology`，保守地从分析投影排除；并不声称已证明原记录错误 |
| 官方端点模式差异 | 550 条 | 标记并保留；其中包含 103 条反向 RecordedBy、380 条乐队署名、67 条艺人间影响 |
| 无日期的艺人间影响 | 67 条 | 保留为结构性证据；不按艺人首发年伪造发生日期 |
| 同名实体 | 存在同名不同 ID | ID 为唯一身份；不按名字自动合并 |

7,407 条五类音乐影响关系中，年度流派统计使用 7,255 条：排除 84 条时间疑点、1 条自环及 67 条无日期关系。三条重复 PerformerOf 不属于音乐影响关系，因此不从这个分母重复扣减。

### 方向及统计含义

原始关系 `新作品 --InStyleOf--> 旧作品` 表示新作品借鉴旧作品。流向图改为 `旧作品流派 → 新作品流派`，并使用新作品发行年作时间代理。`InterpolatesFrom/CoverOf/LyricalReferenceTo/DirectlySamples` 同理。前端结构图保留原始方向，影响事件和流派流向使用传播方向，见 [数据契约](06-前端数据契约.md)。

`notable=true` 不能解读为“榜首”；资料没有提供精确排名、销量和流媒体量。背景叙事中的 Sailor 于 2028 年登顶全球榜单是单独的故事事实，不能推广到每一条 notable 记录。

### 时间截点和缺失

历史特征只使用发行年 ≤ cutoff 的作品和登榜年 ≤ cutoff 的显式登榜事件；无法确定发生时间的关系不进入历史特征。2040 快照的 notable 状态另列为 `observed_notable_work_count`，在更早截面中为 null。该数据没有版本历史，署名可见时间以作品发行年代理，不能将截面回溯等同于真实逐年采集日志。
