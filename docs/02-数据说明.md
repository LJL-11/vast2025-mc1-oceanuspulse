# MC1 数据说明

> 依据官方 `MC1-数据说明-官方.docx` + 本地实测（2026-11-03）整理。

## 总览

| 项 | 值 |
|---|---|
| 文件 | `data/raw/MC1_graph.json`（6.5MB） |
| 结构 | 有向多重图（Directed Multigraph），networkx `node_link_data()` 格式 |
| 节点 | 17,412 个（18 个连通分量） |
| 边 | 37,857 条 |
| 性质 | 官方合成数据，干净但埋了坑（ messy data 也是挑战的一部分） |

**加载方式**：

```python
import json, networkx as nx
G = nx.node_link_graph(json.load(open('data/raw/MC1_graph.json')))
```

## 节点（5 类，共 17,412）

| 类型 | 数量 | 字段 |
|---|---|---|
| Person | 11,361 | `name`、`stage_name`（艺名，可选） |
| Song | 3,615 | `single`（是否单曲）、`genre`、`notable`（是否登顶榜单）、`release_date`、`notoriety_date`（首次登榜年份）、`written_date` |
| RecordLabel | 1,217 | `name` |
| Album | 996 | 同 Song 字段 |
| MusicalGroup | 223 | `name` |

注意：节点的类型字段键名是 **`Node Type`**（带空格），每条边属性只有 **`Edge Type`**；边表示为 `{"Edge Type", "source", "target", "key"}`，source/target 为节点 `id`。

## 关键事实（实测）

- **Sailor Shift**：Person 节点 `id=17255`，相连边 60 条
- **流派 Top10**（Song 维度）：Dream Pop 590、Indie Folk 342、Synthwave 308、Doom Metal 268、Oceanus Folk 235、Alternative Rock 205、Southern Gothic Rock 185、Indie Rock 156、Americana 145、Psychedelic Rock 140
- **时间跨度**：Song release_date 覆盖 1975–2040（合成数据含未来年份，注意过滤异常）
- 示例节点：`{"Node Type": "Song", "name": "Breaking These Chains", "single": true, "release_date": "2017", "genre": "Oceanus Folk", "notable": true, "id": 0}`

## 数据两大来源（官方说明）

1. 众包的音乐影响力知识库：人工标注的采样/翻唱/启发关系
2. 记者 Silas 标注的人气数据：`notable` 与 `notoriety_date` 基于销量/流媒体/榜单排名
