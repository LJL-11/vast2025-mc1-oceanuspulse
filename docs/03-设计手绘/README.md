# 设计手绘过程记录

> 课程要求：设计过程要**用手绘记录下来**。本目录保存三张布局草图与迭代说明。
> 草图为电子化手绘稿（SVG，可直接打印）。**建议答辩前由设计·文档成员打印后用手写批注/描线补充，并拍照附在此目录**，以完全满足"手绘记录"的要求。

## 视觉规范（最终）

- 背景 `#F4F7FA`，卡片白色 12px 圆角；顶部导航深海军蓝 `#17324D`
- 强调色珊瑚橙 `#E8734A`（音乐影响边 / 主曲线），青绿 `#2A9D8F`（人物 / 累计量），蓝 `#5B8FF9`（歌曲），紫 `#7262FD`（专辑），灰蓝 `#9AA7B4`（厂牌）
- 关系编码：**橙色带箭头** = 五类音乐影响（来源 → 受影响者）；**灰蓝细线** = 署名 / 录制 / 成员，不同关系类型必须给不同图例
- 时间窗外节点**淡化而不删除**，避免破坏网络结构
- 明确避开传统柱形图 / 饼图作为主视图：主视图为关系网络、流向矩阵、累积面积、雷达与小倍数证据表

## 交互规范

1. 筛选：实体类型、关系类型、流派、影响关系类型
2. 时间：双滑块时间窗 + 全部 / 2020+ / 2030+ 快捷；点击轨迹图年份可锁定
3. 图操作：滚轮缩放、拖拽平移、悬停聚焦邻域、点击选中、重置视图
4. 钻取：热力矩阵格子 / 影响路径行 → 原始边 ID 与年份证据
5. 联动：选中实体 → 全局焦点条 → 一键跳转对应流派的模块二视图
6. 可分享：`?module=influence|genre|rising` 直达指定模块
