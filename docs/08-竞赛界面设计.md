# OceanusPulse 竞赛界面设计与验证

software · 音乐产业知识图谱可视分析工具，服务 VAST Challenge 2025 MC1 的影响力溯源、流派传播和新星预测任务。

## 视觉方向

深墨蓝、银灰作为界面底色，冰蓝、珊瑚橙、琥珀金表达不同音乐实体与流派。保留 Host Grotesk 和 JetBrains Mono 字体搭配；后者仅用于原始关系 ID。中文使用本机中文字体。图标使用 Lucide 0.468.0，ISC 许可保留在 `web/public/assets/icons/LICENSE-lucide.txt`；两款字体的 OFL 许可保留在 `web/public/fonts`。

最初 taste skill 抽取的 palette 为 forest-pale-lime，用户明确否定绿色后调整为当前墨蓝配色。继续使用 nav-split、soft、space / arrow / stack 的系统与原版 hover / press 动效。原始 triptych 构图转化为分析上下文、真实图谱、实体档案组成的 app-frame。完整技能资源仅保存在被忽略的 `.taste-skill/kit`，页面分发实际使用的系统、布局和交互文件，没有修改技能原件。

全景入口是 Experience + Operate，其余模块是 Operate。三维图谱承担主要视觉表达，图表、数据表和方法说明承担分析任务。没有添加营销评价、价格、虚构结论、照片占位或音频播放声明。

## 操作路径

- 单击选择，悬停读取名称，双击进入对应分析；也可使用搜索、节点标签按钮和侧栏入口。
- 拖空白旋转，拖节点调整位置，滚轮或按钮缩放；方向筛选保留相机与拖拽位置，重置恢复原始布局。
- 从流派进入传播分析时传递选中流派；从实体或候选进入影响力分析时传递选中实体。KeepAlive 按模块使用独立缓存键。
- 图谱支持 PNG 导出，合成可见标签；应用支持导出实际焦点、筛选和时间窗的 JSON。
- 导航支持 Alt + 0—3，全屏演示、手机菜单、浏览器前进与返回。

## 滚动与切换

先加载目标模块，再通过 View Transitions 切换，固定导航不参与位移。内容退出 150ms，进入 260ms，轻微位移和 1—2px 景深变化；不支持时使用短暂的 Web Animations 过渡。连续点击以最后一次请求为准，旧请求不会覆盖新模块或滚动位置。

普通模块切换回到顶部；浏览器返回恢复该模块最近的阅读位置。查看证据、模型检验、排行中的候选定位采用原生平滑滚动。系统开启减少动态效果时直接定位，不播放空间过渡。

图谱的方向流光、空间环绕与选中环共享暂停开关；主动操作后停止自动环绕。离屏、缓存停用和隐藏页面停止 WebGL 绘制，渲染上限约 25fps，DPR 上限 1.5。WebGL 不可用时显示二维后备图谱。ECharts 使用 SVG，按模块加载。

## 验证与适用边界

Vite 生产构建通过；现有前端数据契约测试 8 / 8 通过。浏览器验证仅使用 design-taste-frontend 提供的 headless Chrome 脚本，按单实例顺序执行；没有修改检查器。

四个模块均检查 1440×900、1024×768、820×1180、768×1024、390×844。20 组检查没有横向溢出，全景首页五档尺寸没有布局问题。

布局检查器的剩余项均为 screen-height / hero-fold：手机候选按三张纵向列表展示，分析证据区随图表和数据表自然增长，没有强制塞入固定一屏或两屏。影响力证据手机为 2.73 屏；流派证据桌面 1.46 屏、手机 2.40 屏；预测验证桌面 1.28 屏、手机 2.44 屏；手机候选区约 1.95 屏。这些是针对分析软件的明确例外，未当作“全部检查通过”报告。

Impeccable 静态 detector 对应用源码未发现问题。入口 HTML 中四个 `/assets/taste/...` 样式位于 Vite 的 public 目录，静态检测器按文件目录解析时无法读取；该部分以实际构建和浏览器渲染结果为准。

桌面交互回放 22 / 22 通过，包含真实 WebGL、相机旋转、缩放、节点拖动、整图拖动、暂停、方向筛选、600 实体范围、类型筛选、搜索与联动跳转、图表指标切换、候选联动、共享时间窗、平面模式、真实 JSON 导出、平滑证据滚动、模块回顶、历史位置恢复、连续点击和缓存状态保留。没有未捕获异常。手机与减少动态效果模式 7 / 7 通过，验证静止图谱、无横向溢出、菜单切换、直接证据定位、固定导航与返回位置。

生产版性能检查在 1440 / 390 两档各运行三次，0 FAIL、2 WARN。两项 WARN 都是同一项 JS 体积提醒：初始解析约 684 KiB，其中压缩 JS 约 199 KiB；全部首屏资源压缩传输约 427 KiB，峰值一个 WebGL 上下文，没有失败资源请求。ECharts 与其他分析模块按需加载。Vite 对 Three.js 和 ECharts 的独立 chunk 给出超过 500 kB 的体积提醒，未通过提高阈值隐藏。
