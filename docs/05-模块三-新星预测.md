# 模块三 · Rising Star 画像与 2040–2045 新星预测

> 负责人：周涛（分析 · 模块三）
> 数据快照：2040 年 · 预测窗口：2040–2045 · 复现：`python pipeline/features.py`
> 产物：`data/processed/rising_star.json`（前端 `RisingStar.vue` 读取）

## 1. 任务拆解

官方任务 3 要求：

1. 用可视化刻画“rising star（崛起之星）”的特征；
2. 对比三位艺人的人气与影响力崛起过程；
3. 基于该画像，预测未来五年最可能成为 Oceanus Folk 新星的三位艺人。

本模块把任务拆成四步：

| 步骤 | 做法 | 产出 |
|---|---|---|
| 实体归并 | 把同作品集的艺人/乐队成员合并为“act”，避免同一组合重复占榜 | 10,653 个 act |
| 特征工程 | 产出、登榜、合作、影响力、流派、厂牌、动量等 20+ 维特征 | `features.py` |
| 三人对比 | Sailor Shift（慢热巨星）/ Orla Seabloom（爆发型）/ The Brine Choir（渐进候选） | `comparison` |
| 预测与检验 | 候选池 + 可解释综合分 + Logistic 回溯验证 + Mann–Whitney/FDR | `predictions` / `validation` |

## 2. Rising Star 的操作化定义

### 2.1 实体归并

- 以 `Person` 为基本单位；若艺人隶属 `MusicalGroup`，把团体作品并入其职业轨迹。
- 若两位艺人作品集 Jaccard ≥ 0.8（同一乐队的共同成员），合并为一个 act，选作品署名最多者作代表。
- 这样既保留“乐队”作为整体，又避免 The Brine Choir 五位成员在预测榜上重复出现。

### 2.2 核心特征

| 维度 | 特征 | 含义 |
|---|---|---|
| 产出 | `log_works`、`recent_works_3y`、`momentum`、`last_gap` | 总产出、近三年活跃度、产出动量、空窗期 |
| 质量 | `notable_rate`、`n_hits` | 上榜作品占比、历史登榜作品数 |
| 合作 | `log_collab`、`n_members`、`star_collab_rate` | 外部合作者数、团体规模、高影响力合作者占比 |
| 导师 | `sailor_works`、`n_top_star_works` | 与 Sailor Shift、顶级艺人的共同署名作品数 |
| 影响力 | `influence_in`、`influence_out` | 被引用 / 引用他人的风格、采样、翻唱、歌词引用边 |
| 流派 | `oceanus_share`、`folk_share`、`genre_diversity` | Oceanus Folk 占比、民谣家族占比、流派跨度 |
| 资源 | `label_prestige` | 与 Sailor Shift 关联厂牌（Oceanic Records / Coastal Harmony Studios）的合作比例 |

### 2.3 标签（回溯验证用）

对每个历史快照 `t0`（艺人生涯第 0–7 年，且 `t0 ≤ 2035`）：

- **正样本**：`t0` 前未登榜，且在 `(t0, t0+5]` 内出现首个 `notoriety_date`；
- **负样本**：`t0` 前未登榜，且未来五年仍未登榜。

得到 13,141 个 act-快照样本、1,777 个 act、正样本率 8.5%。

## 3. 三位艺人的职业轨迹对比

| 指标 | Sailor Shift | Orla Seabloom | The Brine Choir |
|---|---:|---:|---:|
| 出道 / 最近活跃 | 2024 / 2040 | 2029 / 2029 | 2034 / 2038 |
| 作品数 | 46 | 8 | 7 |
| 登榜作品数 | 1（2030） | 7（均 2029） | 0 |
| 外部合作者 | 40 | 0 | 1（Sailor Shift） |
| 影响力出边 | 28 | 7 | 4 |
| Oceanus Folk 占比 | 95.7% | 100% | 100% |
| 关联厂牌作品占比 | 41.3% | 12.5% | 42.9% |
| 2040 综合分 | 80.41 | 34.67 | 79.84 |

### 3.1 三种崛起形态

- **Sailor Shift · 慢热→持续型**：2024–2027 连续发片，2028 单曲爆红，此后每年稳定输出；优势是合作网络（40 人）和影响力外溢（28 条出边），属于“长期复利”型。
- **Orla Seabloom · 单年爆发型**：2029 年集中发行 8 部作品，7 部同年登榜，但 2030 年后完全停止；说明“爆发”可以没有持续影响力，登榜数高不等于职业生涯长。
- **The Brine Choir · 渐进型候选**：2034–2038 持续输出，3 部专辑由 Sailor Shift 共同署名，厂牌为 Coastal Harmony Studios；截至 2040 尚未登榜，但导师、动量、资源三项均处于高位。

### 3.2 对比结论

1. **“登榜”是结果，不是过程特征**：Orla 的登榜数远高于 Sailor，但作品数、合作网络和影响力外溢都低，不能仅凭登榜数判断 rising star。
2. **持续性比单年爆发更接近 Sailor 的路径**：Sailor 与 Brine 都是多年连续输出 + 稳定厂牌 + 导师合作，Orla 是反例。
3. **数据中的 Sailor 2028 爆红没有完整体现在 `notoriety_date` 上**：她的 2028 单曲在数据里没有 notoriety 记录，唯一一条是 2030 年的 *Seashell Serenade*；因此本模块同时参考 `notable`、作品年和影响力边，避免只依赖单一字段。

## 4. 预测：2040–2045 年 Top3

### 4.1 候选池

严格条件：

- 出道 ≥ 2028；
- 最近活跃 ≥ 2035；
- 截至 2040 尚无登榜记录（`n_hits = 0`）；
- Oceanus Folk 占比 ≥ 0.5；
- 作品数 ≥ 2。

满足条件的 act 恰好 3 个，全部进入预测；这也说明数据中“下一代 Oceanus Folk 组合”本身就是一个很小的集合。

### 4.2 综合分（Rising Star Score）

综合分是 6 个维度的百分位加权和（0–100），权重在 `features.py` 的 `COMPOSITE_WEIGHTS` 中可调：

| 维度 | 权重 | 构成 |
|---|---:|---|
| 导师效应 | 30% | Sailor Shift 合作作品 ×3 + 顶级艺人合作作品 ×1.5 + 高影响力合作者占比 |
| 上升动量 | 25% | 近 3 年作品数 + 活跃标记 + 空窗期倒数 + 动量 |
| 作品质量 | 15% | 上榜作品占比 |
| 合作资源 | 10% | log(外部合作者 + 团体规模) |
| 影响力 | 10% | 被引用 + 引用他人 + 每作品被引用数 |
| 厂牌资源 | 10% | SS 关联厂牌作品占比 |

### 4.3 结果

| 排名 | act | 综合分 | Logistic 概率 | Bootstrap 第一名占比 | 关键证据 |
|---:|---|---:|---:|---:|---|
| 1 | **The Brine Choir** | 79.84 | 0.796 | 67% | 3 部作品与 Sailor Shift 共同署名；2038 仍有新作；Coastal Harmony Studios；5 人团体 |
| 2 | **Selkie's Hollow** | 70.82 | 0.571 | 0% | 2037 年出道即 5 部作品；*Ballads for the Low Tide* 由 Sailor Shift 共同署名；2 人组合 |
| 3 | **Tidal Reverie** | 64.71 | 0.571 | 33% | 2033–2035 年 5 部作品；*Ballads for the End of Time* 由 Sailor Shift 共同署名；4 人团体 |

三者的共同点：都在 2033–2038 年活跃、都以 Oceanus Folk 为主、都与 Sailor Shift 有直接共同署名，且都合作 Coastal Harmony Studios。区别在于：

- **Brine** 的导师合作最多（3 部）、最近仍在发片（2038），综合分最高；
- **Selkie's Hollow** 最新（2037），但只有 1 部 SS 合作、厂牌资源较弱；
- **Tidal Reverie** 作品集中在 2033–2035，最近活跃度低，但厂牌合作比例较高。

### 4.4 为什么不是 Bea Azure / Kael Storm / Isla Quinn？

- **Bea Azure / Kael Storm（Copper Canyon Ghosts）**：2034–2035 已有多首作品登榜，属于“已破圈”，不符合“未来五年新星”的未登榜条件；但他们是 2031–2035 这一代最成功的 Oceanus Folk 组合，可作为对照。
- **Isla Quinn**：2033 年 *Tidal Whisper* 与 Maya Jensen（Sailor 前队友）合作并当年登榜，已经完成破圈；作品数只有 1，职业轨迹太短。

## 5. 统计检验与模型验证

### 5.1 回溯验证（5 折 GroupKFold，按 act 分组）

| 指标 | 值 |
|---|---:|
| 样本 / act | 13,141 / 1,777 |
| 正样本率 | 8.5% |
| ROC-AUC | **0.619** |
| Average Precision | 0.128 |
| Brier | 0.236 |

AUC 0.62 说明“五年内首次登榜”本身噪声很大，单靠早期特征只能做中等强度的排序；这与合成数据中“爆红事件”的随机性一致。模型不用于给出精确概率，而用于提供与综合分独立的第二信号。

### 5.2 Mann–Whitney U + Benjamini–Hochberg FDR

对每个 act 取一个快照（生涯第 2 年），比较正/负样本：

| 特征 | 正样本均值 | 负样本均值 | p | q (FDR) |
|---|---:|---:|---:|---:|
| `recent_works_3y` | 1.052 | 1.147 | 0.0041 | **0.023** |
| `log_works` | 0.714 | 0.750 | 0.0041 | **0.023** |
| `momentum` | 2.052 | 2.147 | 0.0041 | **0.023** |
| `log_groups` | 0.167 | 0.112 | 0.0072 | **0.030** |
| `genre_diversity` | 0.020 | 0.049 | 0.0342 | 0.116 |
| `notable_rate` | 0.974 | 0.944 | 0.0443 | 0.125 |

前四个特征通过 FDR < 0.05。方向解读：

- **团体归属（`log_groups`）显著为正**：有乐队/组合支持的艺人更容易破圈；
- **流派跨度（`genre_diversity`）方向为负**：专注 Oceanus Folk 的艺人反而更容易在该流派内破圈；
- **作品数与动量**的均值差异很小，说明“多产”本身不是充分条件。

### 5.3 Logistic 系数（7 个模型特征）

| 特征 | 系数 | Odds Ratio |
|---|---:|---:|
| `log_works` | -0.362 | 0.696 |
| `log_groups` | +0.322 | 1.380 |
| `recent_works_3y` | +0.220 | 1.247 |
| `notable_rate` | +0.111 | 1.118 |
| `genre_diversity` | -0.095 | 0.910 |
| `star_collab_rate` | +0.094 | 1.099 |
| `sailor_works` | +0.074 | 1.077 |

`log_works` 为负，表示“作品很多但一直没破圈”的艺人反而概率更低；这与“少而精 + 持续活跃 + 团体/导师支持”的画像一致。`sailor_works` 系数为正但较小，因为历史上与 Sailor 直接合作的样本很少，模型无法给它很高权重；但在候选池内，Brine 的 3 部 SS 合作是决定性差异。

### 5.4 Bootstrap 稳定性

对训练 act 做 200 次有放回重采样并重训：

- The Brine Choir 在 **67%** 的重采样模型中排名第一；
- Tidal Reverie 为 **33%**；
- Selkie's Hollow 为 **0%**。

即“Brine 第一”是稳健的，2/3 名在 Selkie 与 Tidal 之间不确定；两者模型概率相同，综合分通过“近期活跃度 + 厂牌资源”把 Selkie 排在前面。

## 6. 数据坑与局限

1. **`notoriety_date` 稀疏**：全图只有 649 个作品有该字段；Sailor 的 2028 爆红单曲没有 notoriety 记录。本模块因此同时使用 `notable`、作品年份、影响力边和合作网络，而不是只依赖登榜年份。
2. **`notable` 过于普遍**：4,611 个 Song/Album 中 4,297 个 `notable=True`，区分度低，只能作为辅助质量信号。
3. **团体成员重复**：The Brine Choir、Tidal Reverie、Selkie's Hollow 的成员作品几乎完全相同；若不合并，Top3 会被同一组合的成员占满。本模块用 Jaccard ≥ 0.8 合并。
4. **候选池很小**：严格条件下只有 3 个 act，预测结果更像“三选三的排序”，而不是从大池中筛选；这是数据本身的结构，不是方法限制。
5. **综合分权重是专家设定**：百分位加权可解释、可复现，但不是从数据中学到的概率；Logistic 模型提供独立验证，AUC 0.62 说明预测只能作为“候选排序”，不宜过度解读为精确概率。
6. **没有 2040–2045 真值**：验证采用历史 5 年回溯（backtest），只能说明特征在历史 cohort 上的关联强度。

## 7. 前端对接

`data/processed/rising_star.json` 的主要字段：

```
meta                 快照年、预测窗口、样本量、模型特征、权重
comparison[]         三位艺人：timeline / features / descriptive / evidence / rising_star_score
predictions[]        Top3：score / model_probability / strength_percentiles / timeline / evidence
candidates[]         全部候选 act 的完整摘要
leaderboard[]        2040 年 Oceanus Folk 艺人综合分排行（前 80）
validation           交叉验证、单变量检验、Logistic 系数、综合分权重
```

前端 `web/src/views/RisingStar.vue` 只需要读取该 JSON，即可绘制：

- 三人职业轨迹折线（`timeline` 的 `works / cumulative_notable / cumulative_hits`）；
- Top3 雷达图（`strength_percentiles`）；
- 预测卡片（`score / model_probability / bootstrap_rank1_share / evidence`）；
- 验证面板（`validation.cross_validation` + `univariate.tests`）。

> 注意：`data/processed/*.json` 被 `.gitignore` 忽略，部署时需在构建前运行 `python pipeline/features.py`，或把生成物复制到前端静态目录。

## 8. 复现

```bash
pip install -r pipeline/requirements.txt
python pipeline/features.py
```

默认输出 `data/processed/rising_star.json`；`--bootstrap 0` 可跳过 Bootstrap，`--seed` 可换随机种子。
